# Intro Section with Dropdown Navigation

My solution to the [Intro section with dropdown navigation](https://www.frontendmentor.io/challenges/intro-section-with-dropdown-navigation-ryaPetHE5) challenge on Frontend Mentor. A landing-page hero with dropdown navigation menus.

![Intro Section with Dropdown Navigation on desktop](docs/screenshots/desktop.png)

## Features

- **Features** and **Company** dropdown menus whose arrow icons flip when open
- Side navigation drawer on mobile with a dimmed background and the same dropdowns
- Responsive hero layout

## Built with

- Semantic HTML
- CSS with Flexbox, media queries, and transitions
- Vanilla JavaScript for the menus

## Run locally

No build step or dependencies. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
